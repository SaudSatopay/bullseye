## Env vars

| Name | Used by | Where to get it | Without it |
|---|---|---|---|
| `DEMO` | backend, frontend | set by `run-demo` (1 = demo, 0 = live) | defaults to demo |
| `{{PROVIDER}}_API_KEY` | backend | {{the provider's console}} | template narration, responses carry `"mocked": true` |
| `{{DATABASE}}_URL` | backend | {{the database's console}} | in-memory store (works with zero setup); `"store": "memory"` in health |
| `NEXT_PUBLIC_API_URL` | frontend | the backend's base URL (`http://localhost:8000` locally) | the frontend calls the stub |
| `CORS_ORIGINS` | backend | comma-separated | `*` |

`.env.example` lists every name above, never a value.

## Core enums

- `{{verdict}}`: `"{{danger}}" | "{{caution}}" | "{{no_known_risk}}"` <!-- wording rules live here: e.g. never render the word "safe" -->
- `input type`: `"{{text}}" | "{{url}}" | "{{image}}" | "{{voice_transcript}}"`
- `signal.source`: `"deterministic" | "community" | "llm_pattern"`. Scoring uses `deterministic` and `community` only; `llm_pattern` signals display but carry zero verdict weight.
- `assessment`: `"assessed" | "needs_context" | "unsupported_input"`. Whenever it is not `assessed`, the verdict is `null` and the response carries the question to ask instead.
