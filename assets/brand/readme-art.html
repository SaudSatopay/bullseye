The control file

One file every session reads first.

BULLSEYE.md holds the contract, the thesis, the plan, the claims, the judge rounds and the handoff, so a new session, a teammate's agent or a different tool resumes exactly where the last one stopped. This one is the fictional worked example that ships with the skill.

tminus.mjs writes it: the organiser's zone, your clock and an internal deadline with a buffer.

requirements gate

Every rule as a checkable line. The final sweep fails while a [hard] line is open.

judge rounds
